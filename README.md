# polyfoil

Tools I actually use on Windows: local dictation, project memory for AI agents, and OpenCore EFI scaffolding.

Windows’ta gerçekten kullandığım araçlar: yerel dikte, yapay zekâ ajanları için proje belleği ve OpenCore EFI iskelesi.

## Projects / Projeler

| Repo | EN | TR |
|------|----|----|
| [R-Ctrl](https://github.com/polyfoil/R-Ctrl) | Local Windows dictation with Whisper. Hold Right Ctrl, speak, paste. No API key; audio stays on the machine. | Yerel Windows dikte (Whisper). Sağ Ctrl, konuş, yapıştır. API anahtarı yok; ses makinede kalır. [Türkçe README](https://github.com/polyfoil/R-Ctrl/blob/main/README.tr.md) |
| [ProMem](https://github.com/polyfoil/ProMem) | Zero-dependency project memory for any AI agent. The brain lives in `.pm/`, not in a chat log. | Sıfır bağımlılıklı proje belleği. Beyin sohbet günlüğünde değil, `.pm/` içinde. [Türkçe README](https://github.com/polyfoil/ProMem/blob/main/README.tr.md) |
| [HackOS](https://github.com/polyfoil/HackOS-1-Click-OpenCore-EFI) | Windows hardware scan → OpenCore EFI skeleton. Serials are `CHANGEME` placeholders. | Windows donanım taraması → OpenCore EFI iskeleti. Seriler `CHANGEME` yer tutucusu. [Türkçe README](https://github.com/polyfoil/HackOS-1-Click-OpenCore-EFI/blob/main/README.tr.md) |
